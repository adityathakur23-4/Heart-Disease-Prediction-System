
# ❤️ Heart Disease Prediction System

An AI-powered Heart Disease Prediction web application built using **Python, Streamlit, and Machine Learning (KNN)**.

## 🚀 Features

- Heart Disease Prediction
- AI Risk Score
- Dark/Light Mode
- Download Health Report
- Interactive Dashboard
- Beautiful User Interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib

## ▶️ How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
